개인정보처리방침

책 요약 업로더(이하 "이 도구")는 개발자 본인만 사용하는 개인용 프로그램입니다.

수집하는 정보

이 도구는 Google 로그인으로 받은 인증 토큰을 사용자의 컴퓨터에만 저장하며, 외부 서버로 보내거나 다른 사람과 공유하지 않습니다.

정보의 사용

인증 토큰은 사용자가 직접 만든 영상을 사용자 본인의 유튜브 채널에 업로드하고, 썸네일과 재생목록을 설정하는 데에만 사용합니다.

정보의 삭제

컴퓨터에 저장된 토큰 파일을 지우거나 Google 계정 설정의 '타사 앱 및 서비스'에서 접근 권한을 해제하면 언제든 삭제됩니다.

이 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책을 따릅니다.
